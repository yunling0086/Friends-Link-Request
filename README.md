# 友链申请

欢迎申请添加我的网站友链。

## 申请方式

请先参考仓库中的 **[雲凌的BLOG.json](./雲凌的BLOG.json)** 模板，按照相同的 JSON 格式填写你的网站信息。

申请友链有两种方式：

1. **提交 Pull Request（推荐）**
   - Fork 本仓库。
   - 参考 `雲凌的BLOG.json` 创建你自己的友链 JSON 文件。
   - 提交 Pull Request。
   - 等待我审核并添加上线。

2. **提交 Issue**
   - 提交 Issue，并按照 `雲凌的BLOG.json` 模板提供完整的友链信息。
   - 等待我审核并处理。

审核通过后，我会将友链添加到我的友链数据中并上线。

## JSON 模板

请尽量保持字段名称和数据格式与模板一致：

```json
{
  "name": "网站名称",
  "avatar": "头像 URL",
  "description": "网站简介",
  "url": "网站 URL"
}
```

具体填写方式请以仓库中的 **[雲凌的BLOG.json](./雲凌的BLOG.json)** 为准。
